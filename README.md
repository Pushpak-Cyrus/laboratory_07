# LABORATORY_07

An interactive personal portfolio built with Next.js, TypeScript, Tailwind CSS, and Motion.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Edit content

Update `components/data.ts` for your name, contact details, projects, notebook entries, and discovery-map topics. The VIRIDITAS case study content lives in `components/Laboratory.tsx`; every bracketed or deliberately generic statement is intended to be replaced with your verified project information.

## Build

```bash
npm run build
```
